隱私政策

臺灣氣象AI助手

最後更新日期：2025年

一、資料收集與使用

臺灣氣象AI助手（以下簡稱「本擴充功能」）致力於保護您的隱私權。本隱私政策說明我們如何收集、使用和保護您的資料。

1.1 收集的資料類型

  • 城市名稱：當您輸入城市名稱查詢天氣時，我們會將此資訊傳送至後端伺服器以取得天氣資料。
  • 聊天訊息：您在 AI 問答功能中輸入的訊息會暫時儲存在瀏覽器的本地儲存空間（localStorage）中，僅用於提供對話歷史記錄功能。
  • 天氣資料：從中央氣象署（CWA）API 取得的天氣資料會暫時顯示在擴充功能中，不會被永久儲存。

1.2 資料使用目的

  • 提供天氣查詢服務
  • 提供 AI 天氣問答功能
  • 改善使用者體驗
  • 維護服務正常運作

二、資料儲存

本擴充功能使用以下方式儲存資料：

2.1 本地儲存

  • 聊天訊息歷史記錄儲存在您的瀏覽器本地儲存空間（Chrome Storage API）中
  • 所有本地儲存的資料僅存在於您的裝置上，不會上傳至任何伺服器
  • 您可以隨時透過擴充功能的「刪除所有訊息」功能清除本地儲存的資料

2.2 伺服器端處理

  • 當您查詢天氣或使用 AI 問答功能時，相關請求會傳送至我們的後端伺服器
  • 伺服器僅處理您的請求並回傳結果，不會永久儲存您的個人資料
  • 伺服器日誌可能記錄請求時間和 IP 位址，用於服務維護和問題排除

三、第三方服務

本擴充功能使用以下第三方服務：

3.1 中央氣象署（CWA）API

  • 我們使用中央氣象署的開放資料 API 取得天氣資訊
  • 您輸入的城市名稱會傳送至 CWA API 以取得對應的天氣資料
  • 請參考 中央氣象署開放資料平台 的隱私政策

3.2 Groq AI API

  • 我們使用 Groq AI 服務提供天氣問答功能
  • 您的問題和天氣資料會傳送至 Groq API 以產生 AI 回應
  • 請參考 Groq 隱私政策

3.3 Vercel 託管服務

  • 我們的後端服務託管於 Vercel 平台
  • 請參考 Vercel 隱私政策

四、資料安全

  • 我們使用 HTTPS 加密傳輸所有資料
  • API 金鑰儲存在伺服器端，不會暴露在前端程式碼中
  • 我們定期更新和維護系統安全性
  • 我們不會將您的資料出售、租借或分享給第三方

五、您的權利

您對自己的資料享有以下權利：

  • 存取權：您可以隨時查看儲存在瀏覽器中的聊天記錄
  • 刪除權：您可以隨時透過擴充功能刪除所有聊天記錄
  • 拒絕權：您可以選擇不使用本擴充功能，或僅使用天氣查詢功能而不使用 AI 問答功能

六、Cookie 與追蹤技術

本擴充功能不使用 Cookie 或其他追蹤技術。我們僅使用 Chrome Storage API 儲存必要的本地資料。

七、兒童隱私

本擴充功能不針對 13 歲以下的兒童設計。我們不會故意收集兒童的個人資料。如果您是家長或監護人，發現您的孩子向我們提供了個人資料，請聯絡我們，我們會立即刪除相關資料。

八、隱私政策變更

我們可能會不定期更新本隱私政策。重大變更時，我們會在擴充功能中通知您。繼續使用本擴充功能即表示您接受更新後的隱私政策。
